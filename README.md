# KASHIN’S DOLLY GANG — сайт операторской команды

Одностраничный сайт: Главная → Парк техники → (сцена «Механика движения») → Услуги → Проекты → Команда → Контакты.

Сайт: **https://kashinsdollygang.github.io/** (публикуется автоматически через GitHub Actions при каждом push в `main`).

## Стек

- **React 19** — компоненты интерфейса (`src/components`)
- **GSAP 3.15.0 + ScrollTrigger** (версия закреплена) — титульная анимация, раскрытие заголовков, появление карточек, закреплённая сцена «Механика движения»
- **esbuild** — сборка (`scripts/build.mjs`) с разделением кода: тяжёлые модули (three.js) уходят в `assets/chunks/` и грузятся по запросу
- **Three.js** — тестовая 3D-сцена, см. раздел ниже
- Обычный CSS с дизайн-токенами (`src/styles/tokens.css`)
- Шрифты (OFL, лежат в репозитории): Sofia Sans Extra Condensed — заголовки, Golos Text — текст. Обе с кириллицей.
- Модальные окна и мобильное меню — нативный `<dialog>`: фокус внутри, Escape, блокировка фона.

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173 — пересборка при изменениях
npm run build     # production-сборка в dist/
npm run preview   # собрать и открыть dist/ на http://localhost:4173
npm run check     # проверка каталога: 13 позиций, номера, файлы изображений
```

Нужен Node.js 20+.

### Контакты и форма заявки

На сайте показывается только телефон. Впишите номер в `src/data/contacts.js` (`phone`) — он станет кликабельным автоматически.

Форма не имитирует отправку. Пока онлайн-канала нет, она честно сообщает, что заявка не отправлена, предлагает позвонить по указанному телефону и скопировать текст заявки.
Если позже понадобится отправка письмом или в Telegram, добавьте в `CONTACTS` поле `email` или `telegram` — логика формы для них уже есть.

### Добавить проект

Положите постер в `public/images/projects/` и добавьте запись в `PROJECTS` (`src/data/projects.js`) — пример в комментарии файла. Фильтры по типам появятся сами, когда проектов станет больше одного типа. Публикуйте только подтверждённые работы.

### Добавить участника команды

Фото — в `public/images/team/`, запись — в `TEAM_MEMBERS` (`src/data/team.js`). Когда текст «О команде» утверждён, поставьте `ABOUT.placeholder = false`, чтобы убрать пометку «Текст уточняется».

### Характеристики техники

Поле `specifications` в `src/data/fleet.js` — только подтверждённые данные (из документации производителя или от владельца):

```js
specifications: [{ label: "Высота подъёма колонны", value: "…" }],
```

Пока массив пуст, в карточке написано, что характеристики будут опубликованы после сверки.

## Изображения

- `assets-src/` — **оригиналы** (постеры 01–13, логотип, шрифты). Не изменяются.
- `public/images/fleet/` — постеры в WebP (640 и 1120 px), без изменения композиции.
- `public/images/scenes/` — кадрирование нижней части постеров (только техника) для первого экрана, сцены и услуг. Подпись постера на фоне затемнена; пиксели самой техники не затрагиваются.
- `public/images/brand/` — логотип с прозрачным фоном (альфа из яркости оригинала, без перерисовки).

Пересоздать веб-версии после замены оригиналов: `python3 scripts/prepare-assets.py` (нужны Pillow и fontTools).

**Правило проекта:** логотип KASHIN’S DOLLY GANG используется только в интерфейсе (шапка, первый экран, меню, подвал). Его нельзя накладывать на технику. Фото оборудования используются в исходном виде, с заводскими маркировками.

## Анимации

- `src/components/Hero.jsx` — титульная последовательность: шапка → логотип → REC → строки заголовка через маску → проявление техники → видоискатель → подпись и кнопки → один проход света. На desktop кадр слегка «отъезжает» при прокрутке.
- `src/components/MotionScene.jsx` — закреплённая сцена (desktop ≥ 900 px) из трёх реальных кадров парка: «Внимание» (GF-Primo на рельсах), «Масштаб» (операторская стрела), «Присутствие» (Ronin 2). Фото двигаются целиком (2D-анимация слоя), таймкод и шкала привязаны к прокрутке.
- `src/components/JibRig.jsx` — кадр «Масштаб»: фото телескопического крана разделено на слои (`scripts/build-jib-rig.py`) — корневая труба, два выдвижных колена и голова с камерой. Медленный цикл: стрела поднимается вокруг оси на колонне → оба колена одновременно уходят внутрь → выдвигаются → стрела опускается. Камера остаётся горизонтальной. Две петли кабелей под стрелой — отдельный слой на canvas: при складывании они сжимаются и провисают глубже, при выдвижении расправляются, не разрываясь. Цикл идёт только пока кадр на экране.
- `src/components/FleetSection.jsx` — раскладка карточек при первом появлении.
- `src/App.jsx` — раскрытие заголовков секций.
- При `prefers-reduced-motion: reduce`, а также на телефонах сложные скролл-сцены отключаются: показываются статичные кадры.

## 3D-сцена (Three.js) — тестовая

Three.js подключён (`three` в `package.json`) и загружается **отдельным файлом только по запросу** — основной сайт его не скачивает.
React Three Fiber не используется: сцена одна и самостоятельная, обычного Three.js достаточно, лишняя зависимость не нужна.

- Открыть сцену: добавить к адресу `?lab=3d` — https://kashinsdollygang.github.io/?lab=3d . Обычным посетителям она не видна (`THREE_LAB_PUBLIC` в `src/data/three.js`).
- Код: `src/three/createRailScene.js` (сцена), `src/components/ThreeLab.jsx` (React-обёртка, прокрутка, резервные режимы), `src/three/webgl.js` (проверка WebGL), стили `src/styles/three.css`.
- В сцене **нет моделей техники**: рельсы и дуга подъёма — условная схема линиями, тележка и кран — пустые пунктирные слоты.
- При прокрутке слот тележки едет по рельсам, затем поворачивается ось стрелы. Кадр рисуется только при изменении прокрутки (без постоянного цикла).
- Телефоны: сниженное разрешение рендера, без сглаживания, режим `low-power`. `prefers-reduced-motion`: один статичный кадр без привязки к прокрутке. Нет WebGL или контекст потерян: статичное фото реальной тележки и пояснение.

### Как подключить реальную модель

1. Нужен настоящий 3D-ассет конкретной модели в формате **GLB/GLTF** (от производителя, по лицензии, или смоделированный по реальному образцу). Сгенерированные «похожие» модели не используем.
2. Положите файл в `public/models/`, например `public/models/gf-primo-dolly.glb`.
3. В `src/data/three.js` заполните `DOLLY_MODEL` (`url`, `scale` так, чтобы 1 единица = 1 метр, `rotationY`, `offset`). Для крана — `JIB_MODEL`, и укажите `armNode` — имя узла стрелы внутри GLB, который должен поворачиваться, и `pivot`.
4. Для тяжёлых моделей лучше заранее сжать файл (например, gltf-transform с Meshopt/Draco); DRACO-декодер сейчас не подключён.

## Публикация

`.github/workflows/deploy.yml` собирает сайт и публикует `dist/` в GitHub Pages при каждом push в `main`.
В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.

Пути в сборке относительные (`./assets/…`, `images/…`), поэтому сайт работает и в корне адреса, и в подпапке, и на собственном домене.
Если подключите свой домен, обновите `canonical`, `og:url`, `og:image` в `src/index.html` и адреса в `public/sitemap.xml`.

## Ronin 2 в кадре «Плавность»

`src/components/RoninRig.jsx` — анимация по фото. `scripts/build-ronin-rig.py` разбирает постер на слои (`public/images/scenes/ronin-rig/`): `base` (сцена без кольца, фон под ним дорисован), `ring` (кольцо с зажимами, вырезано GrabCut) и `front` (рукоять, голова, блэнда, кабели — поверх кольца). Кольцо слегка покачивается вокруг низа подставки, камера остаётся ровной и неподвижной. Это 2D-анимация фотографии. Играет, пока кадр на экране; при `prefers-reduced-motion` — без движения.
